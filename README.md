# structured-concurrency-quarkus

> **⚠️ This repository is archived.** It shows the preview API of Java 21, which
> changed before Structured Concurrency became final in Java 25. For current
> examples, see the [structured-concurrency](https://github.com/SvenWoltmann/structured-concurrency)
> repository and the article
> [Structured Concurrency with Java](https://www.happycoders.eu/java/structured-concurrency-structuredtaskscope/).
Quarkus demo application to show how to introduce structured concurrency using StructuredTaskScope.
